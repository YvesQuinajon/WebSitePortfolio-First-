Research Workflow & Grant Management System

Managemen System

Project Description

Develop a Web Based Research Management platform that digitizes and automates the application and approval process for University Research activities such as publication incentives, research grants, thesis/dissertation submissions. The system replaces manual document routing by automatically forwarding submitted research papers to the correct approving authorities based on predefined approval hierarchies.

Planned Features

  • Digital research application submission
  • Automated multi-level approval workflow
  • Automatic routing to assigned evaluators
  • Real-time application status tracking
  • Revision and feedback requests
  • Notification system for pending approvals
  • Centralized research document repository

Technologies

  • HTML (File Receipts Automatically Generated)
  • Built automated approval workflows using Power Automate
  • Configured role-based routing logic (Adviser → Chair → Dean → Research Office)
  • Microsoft Excel
